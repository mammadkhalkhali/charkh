# چرخ — سایت فروش خودرو

رابط کاربری بخش مشتری (دسکتاپ و موبایل)، راست‌چین، فونت پیدا، زبان طراحی الهام‌گرفته از اپل.

## فایل‌ها
- `Charkh.dc.html` — سورس طراحی (همه صفحه‌ها: خانه، جستجو و فیلتر، جزئیات خودرو، مقایسه، قیمت روز بازار، نشان‌شده‌ها، موبایل)
- `index.html` — نسخه تک‌فایل و مستقل، بدون نیاز به هیچ چیز دیگر
- `fonts/` — فونت پیدا (۹ وزن)
